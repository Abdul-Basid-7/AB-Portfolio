# 🚀 MERN Portfolio Website

A modern full-stack developer portfolio built using the MERN stack with a premium responsive UI, admin dashboard, GitHub repository synchronization, Cloudinary image uploads, JWT authentication, and production-ready architecture.

---

## 🌟 Features

### 🎨 Frontend
- Modern responsive UI
- Glassmorphism design
- Framer Motion animations
- Mobile responsive navigation
- Smooth scrolling sections
- Skeleton loading states
- Dynamic featured projects
- Functional contact form

### ⚙️ Backend
- RESTful API architecture
- JWT Authentication
- Protected admin routes
- CRUD project management
- GitHub repository sync
- Cloudinary image uploads
- Nodemailer email integration
- MongoDB Atlas database

### 🛠 Admin Dashboard
- Secure admin login
- Add/Edit/Delete projects
- Feature/unfeature projects
- GitHub sync system
- Cloudinary uploads
- Responsive dashboard UI

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/mern-portfolio.git
```

---

### Install Frontend Dependencies

```bash
cd client
npm install
```

---

### Install Backend Dependencies

```bash
cd server
npm install
```

---

## ▶️ Run Application

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend

```bash
cd client
npm run dev
```
